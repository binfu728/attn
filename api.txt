# DINOv3-Large 全参微调复现 OlmoEarth (PASTIS 数据集) 改造指南

## 核心改造思路 (OlmoEarth 论文 Section 3.3)
为了解决原先将多时相图像在“像素空间平均”导致物候特征丢失、mIoU 暴跌至 23 的问题，本指南采用 OlmoEarth 的标准做法：
1. **输入阶段**：在时间轴均匀采样 12 个时相，拼成 36 通道 (12×3) 的伪图像以兼容 MMSegmentation 的数据增强流水线。
2. **Backbone 阶段**：在送入 DINOv3 前将 36 通道拆解为 12 个独立 Batch；在 DINOv3 提取出高维特征后，再在时间维度进行特征池化 (`Mean Pooling`)。
3. **防 OOM 策略**：由于时间维度展开会将实际送入 Backbone 的图片数放大 12 倍，针对 A40 (48G) 显卡，将分辨率降至 `224x224`，并设定 `batch_size=1` 结合 AMP 混合精度训练。

## 步骤 1：重新生成时序预处理数据 `pack_to_rgb.py`

请创建或覆盖 `pack_to_rgb.py`，运行此脚本提取 12 帧时序数据，生成 `.npy` 文件。

```python
import numpy as np
from pathlib import Path
from tqdm import tqdm

pastis_root = Path('/mnt/ht2_nas2/00-model/00-fb/mmseg_data/PASTIS-R') 
s2_dir = pastis_root / "DATA_S2"
# 新文件夹：保存 36 通道的时序堆叠数据
out_dir = pastis_root / "DATA_S2_RGB_TIMESERIES" 
out_dir.mkdir(parents=True, exist_ok=True)

_RGB_IDX = [2, 1, 0] 
T_TARGET = 12 # OlmoEarth 设定的最大时间步数

s2_files = list(s2_dir.glob("S2_*.npy"))
print(f"Found {len(s2_files)} files. Start processing...")

for s2_path in tqdm(s2_files):
    out_path = out_dir / s2_path.name
    if out_path.exists(): 
        continue 
    try:
        s2 = np.load(s2_path).astype(np.float32) # (T, 10, H, W)
        s2_rgb = s2[:, _RGB_IDX, :, :]           # (T, 3, H, W)
        
        # 在时间维度均匀采样 12 帧
        T_current = s2_rgb.shape[0]
        indices = np.linspace(0, T_current - 1, T_TARGET, dtype=int)
        s2_sampled = s2_rgb[indices]             # (12, 3, H, W)
        
        # 变形成 (H, W, 36) 的伪图像，兼容 mmseg
        img_36 = s2_sampled.transpose(2, 3, 0, 1).reshape(s2.shape[-2], s2.shape[-1], T_TARGET * 3)
        np.save(out_path, img_36.astype(np.float16))
    except Exception as e:
        print(f"Error processing {s2_path.name}: {e}")

print("Preprocessing Finished!")

步骤 3：修改 Backbone 加入时间特征池化 custom_models/dinov3_backbone.py

在 DINOv3BackboneMmseg 类中，修改 forward 方法。使得它能够自动拆解 36 通道，通过 DINO 后在特征层进行 mean pooling。
code Python

def forward(self, x):
        # 输入 x 的形状为 (B, 36, H, W)
        B, C_in, H, W = x.shape
        T = C_in // 3  # T = 12
        
        # 1. 展开时间维度到 Batch 维度：形状变为 (B * 12, 3, H, W)
        x = x.view(B, T, 3, H, W).view(B * T, 3, H, W)
        
        # 2. 送入 DINO 提取特征
        # out["1"] 到 out["4"] 的形状将是 (B * 12, C_feat, H_f, W_f)
        out = self.adapter(x)
        
        # 3. 将特征重新折叠并进行时间维度的 Mean Pooling
        res = []
        for k in ["1", "2", "3", "4"]:
            feat = out[k]
            _, C_feat, H_f, W_f = feat.shape
            
            # 还原形状: (B * 12, C_feat, H_f, W_f) -> (B, 12, C_feat, H_f, W_f)
            feat_unfolded = feat.view(B, T, C_feat, H_f, W_f)
            
            # 对时间维度（dim=1）求平均！OlmoEarth 的核心操作
            feat_pooled = feat_unfolded.mean(dim=1) 
            
            res.append(feat_pooled)
            
        return tuple(res)
